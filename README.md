
# World Layoffs Data Cleaning Using MySQL

## 📌 Project Overview
This project focuses on cleaning a world layoffs dataset using MySQL.
The goal is to improve data quality and prepare the dataset for further analysis.

## 🛠️ Tools Used
- MySQL
- MySQL Workbench

## 🎯 Project Objectives
- Identify and remove duplicate records.
- Standardize data formats and inconsistent values.
- Handle NULL and blank values.
- Remove unnecessary records where appropriate.
- Prepare a clean dataset for data exploration.

## 🧹 Data Cleaning Process
1. Created a staging table to preserve the raw data.
2. Identified and removed duplicate records.
3. Standardized company and industry information.
4. Standardized date formats.
5. Handled NULL and blank values.
6. Removed unnecessary records where appropriate.

## 💡 Skills Demonstrated
- SQL Queries
- Common Table Expressions (CTEs)
- Window Functions
- Data Cleaning
- Data Standardization
- Handling Missing Values
